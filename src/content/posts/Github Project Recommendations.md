# [1.Kzumi](https://github.com/Predidit/Kazumi)
## <span style="color:#2ea44f">基于自定义规则的番剧采集APP，支持流媒体在线观看，支持弹幕，支持实时超分辨率。</span>
### ![首页推荐](https://img.coccineus.uk/file/1787573876076__A7220DAB-6424-422B-B2FA-B0AFE98018DF_.png)
### 支持按季度查看番剧![时间表](https://img.coccineus.uk/file/1787574790097__9B5AFD8B-7947-43EF-84DF-43E4CBFBDB1F_.png)
>[!TIP]
>**官方规则仓库🎊[Kazumu Rules](https://github.com/Predidit/KazumiRules)<br>超分辨率支持质量和效率两档开启后画质提升明显✨[Anime4K](https://github.com/bloc97/Anime4K)**
### ![自定义规则和超分辨率](https://img.coccineus.uk/file/1787575135589_屏幕截图_2026-08-24_203826.png)
### 目前在Github上已有近30k stars<br>作者链接🪄[Pinned](https://github.com/Predidit)<br>项目仓库🪄[Kzumi](https://github.com/Predidit/Kazumi)
